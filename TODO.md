# LiveCam — resultados

## Transmissão pública em uma sala por link — concluído

- [x] Uma pessoa pode abrir a página de transmissão em um celular.
- [x] O navegador solicita acesso à câmera e ao microfone antes da live.
- [x] O transmissor vê uma pré-visualização local da câmera.
- [x] O transmissor pode iniciar e encerrar a transmissão.
- [x] A sala aceita uma única pessoa transmissora.
- [x] O sistema não grava, não oferece replay e não armazena áudio ou vídeo.

## Link e visualização pública — concluído

- [x] Ao iniciar uma sala, o sistema gera e exibe um link público compartilhável.
- [x] Espectadores podem abrir o link sem login.
- [x] A página pública mostra a transmissão ao vivo do transmissor.
- [x] A página informa quando a sala está aguardando, conectando, ao vivo, encerrada ou indisponível.

## Sinalização e estados de conexão — concluído

- [x] O servidor coordena entrada e saída de participantes e troca de ofertas, respostas e candidatos ICE.
- [x] O sistema trata ausência de câmera/microfone, permissão bloqueada, desconexão e tentativa de restabelecimento.
- [x] O transmissor vê a contagem de espectadores conectados.
- [x] O espectador recebe mensagens compreensíveis quando a live ainda não começou, terminou ou não está disponível.

## Interface responsiva — concluído

- [x] A experiência funciona em celular e desktop.
- [x] Os controles principais têm tamanho confortável para toque.
- [x] O vídeo e o estado da conexão têm prioridade visual.
- [x] Existe controle de áudio e tela cheia na visualização, quando suportado pelo navegador.
